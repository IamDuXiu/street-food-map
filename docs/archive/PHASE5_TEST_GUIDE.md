阶段 5 不是公开发布。服务端只绑定可信局域网：运行 `npm run dev:lan`，终端会显示本机和同网 IPv4 地址。只使用可信 Wi‑Fi/个人热点，测试结束立即按 Ctrl-C 停止；不要向受试者提供 `/admin` 地址、管理员密码、备份、数据库或上传目录。局域网地址不是公网安全边界，也不代表真实 AMap 或生产代理已经验证。

浏览器定位属于安全上下文能力。参与者手机通过 `http://局域网IP` 访问时，通常不能正常授予定位权限；本轮手机任务应使用区域选择器，并把“定位不可用后能否顺利回退”作为观察项。定位同意流程只在主持人电脑的 `http://localhost` 内部演练，不计入手机真人测试结果。不要为绕过此限制临时安装未知证书；若后续必须验证手机定位同意流程，应另行确认 HTTPS 测试地址。参见 [W3C Geolocation 规范](https://www.w3.org/TR/geolocation/)。

## 真实数据准备与核验清单

第一轮建议集中在一个科技园步行区准备 20–30 份，不要为了凑数量扩大区域。使用 `docs/templates/phase5-import-template.csv`；第一行已经是中文列标题，请勿改名、增删或调整顺序。你可以一人完成，但每一份都必须独立于豆瓣等线索逐项核验：

- 店名、可步行地址、所属试点区和餐食名称明确；不是泛泛的“这家店不错”。
- 导入表按人民币元填写价格（例如 `18` 或 `18.5`），目标收录价格不超过 ¥25；超过 ¥25 的涨价只作为后台变化记录，不应出现在公开饭签。
- 观察日期近期且不超过 180 天；未来日期、无法确认日期的记录退回。
- 坐标为 GCJ-02，经纬度与门店位置人工复核；不要把受试者实时定位写入数据库。
- 至少有门店菜单、现场价签或独立可验证菜单证据；线索来源与正式事实分开记录。
- 来源 URL/线索仅供后台追溯，不复制豆瓣内容、不抓取豆瓣、不把外部原文作为公开描述。
- 图片权利已确认、无姓名/电话/订单号/二维码/人脸等敏感信息；无法确认时仅后台保留或不用。
- 录入前再次对照证据复核店名、餐食、价格、日期、坐标和公开状态；如果只有你一人，至少把“现场记录”和“录入复核”分成两个时间点，导入后再从用户端抽查。

最终是否达到方案要求的真实数据门槛，必须在复盘时按阶段方案决定；演示 seed 不得计入真实数据数量或测试指标。

## 统一主持任务

主持人先说明：“我们测的是产品，不是你。不会收集姓名、电话、微信或精确轨迹；你可以随时停止。请按你平时做决定的方式操作，我不会提示答案。”不要把任务拆成教程，也不要在用户卡住前暗示按钮位置。

每人从首页开始，任选一个主持人指定的样板区任务：

1. 在指定区域找到一份不超过 ¥20 的单人餐，并说出看到的价格和最近核验日期。
2. 说明这份信息为什么可信、什么情况下不会把它当作当前事实。
3. 判断是否需要导航并自行点击（不要求真的出发）。
4. 如果自然产生纠错或价格变化想法，可自行选择投稿；不要要求每个人投稿，也不要暗示“投稿才算完成”。

记录 30 秒计时点：从首页可操作且定位回退提示结束后，到用户第一次明确指出符合条件的店/餐。记录是否完成、当时说出的价格/距离、是否理解核验状态、是否点击导航、是否自然投稿和主要卡点。手机局域网流程记录 `lan_unavailable`、`denied` 或 `not_requested`；主持人本机内部演练可记录 `localhost_allowed`，但不能把它混入手机真人指标。不追问精确位置。

观察表使用 `docs/templates/phase5-observations.csv`。匿名编号应为 `P01`、`P02` 等，不得填姓名、电话、微信、邮箱、精确住址或原始定位坐标。

## 招募邀请文案

你好，我们正在测试一个深圳平价餐食地图的本地原型，想邀请你用 10–15 分钟完成一个找饭任务。我们只测产品是否好用，不评价你的答案；不会收集姓名、电话、微信或精确位置，你可以随时停止。测试只在可信局域网进行，地址不会公开，测试结束立即关闭服务。如果你愿意参加，请回复一个方便的时间段即可，不需要提供个人资料。

## 故障与回退

- 真实数据不足：立即暂停真人测试，使用演示数据只能做主持人内部演练，不能计入指标。
- 局域网不可达：让受试者停止操作，回到主持人本机 Demo；不要临时开放公网端口或关闭鉴权。
- 页面错误/服务退出：记录时间和页面，不让受试者重复提交；主持人先检查终端，再决定是否终止本场。
- 定位拒绝或不可用：让用户继续用默认样板区完成任务，不请求或记录精确坐标。
- 投稿上传失败：保留投稿成功页和查询码；不把“图片失败”说成“投稿没创建”，不要求用户交出查询码给主持人。
- 发现价格、来源或隐私问题：下线相关公开记录，保留后台证据和审计，先备份再修复；不得用手工改库掩盖问题。

## 复盘方式

测试结束填写 `docs/templates/phase5-retrospective.md`，只汇总匿名编号和行为信号。报告必须同时写样本数、30 秒完成率、核验状态理解、复用意愿、严重来源/隐私问题、导航信号、自然投稿信号和主要卡点，并得出“继续 / 调整 / 停止”之一。小样本结果不能包装为市场结论；若出现无法解释的价格来源或严重隐私问题，应停止扩展。
