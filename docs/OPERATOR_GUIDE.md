# 街头饭签本地操作手册

这是一份给产品负责人和审核人员的本地 MVP 手册。系统使用本机 SQLite 和 `uploads/` 文件夹；没有公网部署、用户账号、云存储或真实腾讯生产代理。任何“公开”动作都应先完成独立核验和隐私检查。

## 从零启动

1. 安装 Node.js 20.9 或更高版本，并在项目根目录安装依赖：

   ```bash
   npm install
   ```

2. 首次启动前设置管理员密码（至少 12 个字符）：

   ```bash
   ADMIN_PASSWORD='请替换为本机密码' npm run setup
   ```

   `setup` 会幂等创建/升级 `data/budget-map.sqlite`、`uploads/` 和 `backups/`，并写入本地 `.env.local` 的随机会话密钥。不要把 `.env.local`、数据库或备份发给别人。

3. 启动本地服务：

   ```bash
   npm run dev
   ```

   用浏览器打开 `http://localhost:3000`；后台入口是 `/admin/login`。不配置腾讯 Key 也能使用 Demo 地图。

4. 可重复的全新环境检查：

   ```bash
   npm run fresh-start
   ```

   检查会在系统临时目录用 README 同一套 `setup`、公开 repository 查询和备份实现建立短生命周期环境，然后清理临时目录；不会删除或覆盖项目的 `data/`、`uploads/`、`backups/`。

## 本地配置速查

通常只需要在首次 `setup` 时提供 `ADMIN_PASSWORD`。其余配置写入项目根目录的 `.env.local`，不要提交或分享该文件。

| 配置 | 用途 | 本地默认/注意事项 |
|---|---|---|
| `ADMIN_PASSWORD` / `ADMIN_PASSWORD_HASH` | 初始化管理员密码 | 优先长期保存哈希，不要把明文密码写进代码 |
| `ADMIN_USERNAME` | 后台账号名 | 默认 `admin` |
| `SESSION_SECRET` | 签名后台会话和匿名来源指纹 | 必须至少 32 个字符；`setup` 可生成本地随机值 |
| `DATA_DIR` / `DATABASE_PATH` | SQLite 数据目录和文件 | 默认 `data/` 与 `data/budget-map.sqlite` |
| `UPLOADS_DIR` / `BACKUPS_DIR` | 图片和备份目录 | 默认 `uploads/` 与 `backups/` |
| `NEXT_PUBLIC_MAP_MODE` | `demo` 或 `tencent` | 当前默认 `demo` |
| `NEXT_PUBLIC_TENCENT_MAP_KEY` | 本地真实腾讯 JS API GL 底图测试 | 没有 Key 时留空；不要提交 Key；需在腾讯控制台配置域名白名单 |
| `TRUST_PROXY` | 是否读取可信代理提供的来源地址 | 本地保持 `0`；只有可信代理剥离伪造头后才可设 `1` |

## 日常审核

- 用户在 `/submit` 匿名提交四类信息：新地点、价格变化、地点纠错、停业。成功页只显示一次查询码；查询码只用于 `/submit/status`，不能当图片上传令牌。
- 在 `/admin/submissions` 打开投稿。先看类型化字段、证据缩略图、权利确认和人工隐私状态，再选择“通过 / 待核验 / 重复 / 拒绝”。失败或待核验不会改变正式公开数据。
- 只有 `new_place` 和 `new_price` 的证据可以在批准时勾选公开；纠错和停业证据始终为后台私有。公开图片必须已经权利确认、完成隐私复核，并和正式核验价格关联。
- 如果图片含姓名、电话、订单号、二维码、脸或其他敏感信息，保持 `admin_only`，或上传已人工脱敏的替代图。替代图仍需重新检查；原图不会删除，也不会公开。
- 新价格可以记录高于 15 元的涨价；公开地图以店级门槛收录（店内至少一份 ≤15 元单人餐），其余餐食如实展示，sanity 上限 200 元。

## 导入真实数据

进入 `/admin/import`，先点击“下载 CSV 导入模板”，在表格软件中填写后再上传、预览和确认，不需要编辑代码。模板列标题已经是中文，请勿改名、增删或调整顺序；旧英文模板仍可导入。坐标填写 GCJ-02，金额以元填写，观察日期不能超过未来；同一批次的多餐食会归并到地点，重复地点会阻止提交。CSV 不接收图片路径，也不会自动制造证据媒体；图片必须走投稿或后台安全上传链路。

**演示数据清理警告：** 不要直接删除默认数据库、`uploads/` 或 `backups/`。先在 `/admin/exports` 或 `npm run backup` 生成备份，确认 ZIP 可以校验，再使用一个明确的新 `DATA_DIR`/`UPLOADS_DIR` 做真实数据演示，或由熟悉 SQLite 的人员在停机后处理。误删时优先停止服务、保留现场并从备份恢复，勿继续写入。

## 备份与恢复

备份：

```bash
npm run backup
```

备份包含一致性 SQLite 快照、关键表、投稿/审核记录、媒体文件和 SHA-256 清单。恢复是覆盖操作：先停止正在写入的服务，再做只读校验；命令会先自动备份当前数据，且必须输入确认词：

```bash
npm run restore -- --from backups/<文件>.zip --confirm RESTORE-BUDGET-MAP
```

恢复失败会保留原库和原上传目录。恢复完成后可运行 `npm run fresh-start` 作为“软件能否初始化”的附加检查；它只使用临时目录，不能验证刚恢复的默认数据库。要验证恢复结果，请启动应用，实际检查公开地图、后台投稿、公开媒体和 `/admin` 数据，再运行 `npm run maintenance`。

```bash

```

手机通过 HTTP 局域网地址访问时，浏览器通常不会允许定位。真人测试请使用“当前区域”入口，从南山区进入科技园商圈，并观察定位失败后回退深圳全市的体验；定位同意只在主持人电脑的 `localhost` 演练。不要临时安装未知证书，后续若必须验证手机定位同意再单独准备 HTTPS 地址。

## 常见故障

- 页面打不开：确认 `npm run dev` 仍在运行；端口占用时停止旧进程或换端口，不要删除数据库。
- 无法登录：确认使用运行 `setup` 时的密码；需要改密码时使用后台既有密码脚本并保存新密码，旧会话会失效。
- 投稿图片失败：保留成功页的查询码；页面会列出失败数量并允许重试。服务端只接受 JPEG/PNG/WebP，单张最多 10MB、每投稿最多 5 张。
- 地图显示 Demo：这是无 Key 的正常降级。真实腾讯 JS API GL 路径尚未在真实 Key、生产代理或域名白名单下验证，不要把本地结果当生产承诺。
- 导入被拒：先看逐行预览；修正坐标系统、日期、金额、重复地点或来源字段后重新选择文件。确认按钮只在整批通过时出现。
- 测试启动报 IPC 权限错误：这是受限沙箱无法让 Playwright/tsx 创建临时 socket 的环境问题，不要关闭校验；在正常本机终端重跑 `npm run test:e2e`。
- 局域网入口无法启动：确认端口未被占用并在允许监听本机端口的终端重跑 `npm run dev:lan`；不要改成公网绑定或关闭后台鉴权。

## 安全底线

管理员密码、`SESSION_SECRET`、数据库、备份和上传目录只保存在受控本机。公网若未来接入，必须由明确配置的可信反向代理剥离客户端伪造的转发头，并重新审查 Origin、Cookie、备份权限和媒体访问；当前项目没有公司主体、域名或公网部署。不要把来源 URL、审核备注、投稿原始内容、查询码哈希或文件路径复制到公开页面或截图。
