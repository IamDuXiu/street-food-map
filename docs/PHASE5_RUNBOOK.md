# 阶段 5 · 真实数据进库与开测交接手册

状态：截至 2026-09-09，阶段 0–4 已完成并验收，阶段 5 的工程准备已就绪且全部提交；真实数据采集与真人测试尚未执行，本手册把「实地采集到的真实餐食 → 安全变成公开饭签 → 完成局域网真人测试」串成一条可照做的流水线。它不是重复既有手册，而是按顺序执行清单，细节链接到对应手册。

红线：每份真实餐食都必须独立核验——店名、具体餐食、≤¥25、180 天内观察日期、GCJ‑02 坐标、菜单/价签证据、隐私与版权。演示 seed、空模板、豆瓣原文一律不计入真实数量。线索与正式事实分离；来源 URL 仅供后台追溯。

## 1. 两条真实数据进入路径（选一条为主，同一批线索不要混用）

| | 路径 A：CSV 两阶段导入（默认，推荐） | 路径 B：线索池 UI（可选，适合豆瓣线索再核验） |
|---|---|---|
| 入口 | `/admin/import` | `/admin/leads` → 选线索 → 补地址与坐标 → 提交 |
| 操作 | 下载 `docs/templates/phase5-import-template.csv`（16 个中文列名，勿改）→ 填表 → 上传 → 服务端预览（只读）→ 整批通过后确认 → 单事务原子提交 | 勾选候选餐食 → CoordinatePicker 图上点选 GCJ‑02 坐标 → 勾选三个核验事实 → 保存草稿 → 预览 → 确认提交（单事务；成功后草稿自动删除） |
| 适用 | 你实地一次性采集一批，表格整理后整体导入 | 从库内 `source_leads` 34 条候选（对应 `outputs/` 候选清单）逐条人工复核转正式 |

两套都复用同一套预览与提交规则（坐标范围、重复地点、来源线索、external_lead 不得当核验方式），最终都写入正式 `places / menu_items / price_reports`。细节见 [OPERATOR_GUIDE.md](OPERATOR_GUIDE.md)「导入真实数据」。

## 2. 步骤（数据就绪后按序执行）

- **Step 0 · 备份**：`npm run backup`，确认生成 ZIP 可校验。之后任何写默认库前都先备份。
- **Step 1 · 隔离演练（不碰默认 `data/`）**：用全新临时目录跑通一遍导入与抽查。设 `DATA_DIR`、`UPLOADS_DIR`、`BACKUPS_DIR` 指向新目录 → `ADMIN_PASSWORD='…' npm run setup` → 启动后按路径 A 或 B 导入该批 → 在用户端抽查地点、价格、核验日期与公开过滤（含 375px 无横向溢出）→ 失败即暂停排查；通过后清理临时目录。参考 [OPERATOR_GUIDE.md](OPERATOR_GUIDE.md) 的配置表与 `npm run fresh-start` 的隔离理念。
- **Step 2 · 正式导入默认库**：用隔离演练通过的同一批数据 → `/admin/import` 预览全绿 → 确认（单事务，失败自动回滚）→ 用户端抽查与后台事实一致 → 再 `npm run backup` 保留含真实数据的备份。
- **Step 3 · 主持人演练**：本机 `localhost` 演练定位同意；手机经局域网演练定位不可用/拒绝后的区域选择器回退、空结果、投稿失败与停止服务。能按故障回退、不诱导不代做才开测。
- **Step 4 · 开测**：`npm run dev:lan`（仅可信 Wi‑Fi/个人热点）。首轮 6–8 人、最多 10 人、每人 10–15 分钟；统一任务卡；匿名编号 P01…；记录观察表；结束后立即 Ctrl-C。不向受试者提供 `/admin` 地址、管理员密码、数据库或上传目录。主持任务、观察/复盘模板见 [PHASE5_TEST_GUIDE.md](PHASE5_TEST_GUIDE.md)。
- **Step 5 · 复盘**：样本数、30 秒完成率、核验状态理解、复用意愿、导航与自然投稿信号、严重来源/隐私问题，给出「继续 / 调整 / 停止」。指标口径见系统方案 §15；演示 seed 不计入。

## 3. 故障与回退

- 真实数据不足 → 立即暂停，演示数据只可做主持人内部演练，不计入指标。
- 导入被拒 → 看预览逐行错误（坐标系统、日期、金额、重复地点、来源 URL），修正后重新选择。
- 局域网不可达 / 服务退出 → 让受试者停止，回到主持人本机 Demo；不要临时开放公网端口或关闭鉴权。
- 定位拒绝或不可用 → 用户继续用区域选择器完成任务，记录回退，不请求或记录精确坐标。
- 投稿上传失败 → 保留成功页查询码；图片失败不代表投稿未创建。
- 发现价格、来源或隐私问题 → 下线相关公开记录，保留后台证据与审计，先备份再修复；不得手工改库掩盖。
